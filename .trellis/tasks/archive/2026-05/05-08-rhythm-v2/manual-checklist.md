# Rhythm v2 手动验收清单

> 按照 `.trellis/spec/frontend/wpf-desktop-app.md` §6 要求，视觉改动需人工验收。

## 启动前准备

1. 确保 `state.json` 有 2+ 项 todo（至少 1 已完成 + 1 未完成）
2. 如果没有，先运行 app → 右键"编辑事项" → 添加测试数据

---

## ✅ R1: CheckBox 自定义 Template

**预期**：
- 未选中：18×18 圆角 4px，描边 `#5A5A5E`（灰），透明背景
- 选中：填充 `#0A84FF`（iOS 蓝），白色勾号

**验收步骤**：
- [ ] 启动 app，观察未选中的 CheckBox：圆角明显，描边为深灰色
- [ ] 点击勾选一项，CheckBox 变为蓝色填充 + 白勾
- [ ] 再次点击取消勾选，恢复灰色描边

---

## ✅ R2: CheckBox hover 态

**预期**：鼠标悬停时描边升亮至 `#8E8E93`（更亮的灰）

**验收步骤**：
- [ ] 鼠标移到未选中的 CheckBox 上，描边变亮
- [ ] 鼠标移开，描边恢复原色

---

## ✅ R3: 选中动画

**预期**：勾选时有 150ms 动画（勾号从 0 缩放到 1，带 BackEase 弹性）

**验收步骤**：
- [ ] 快速点击勾选/取消多次，观察勾号有"弹出"动画
- [ ] 动画流畅，不卡顿

---

## ✅ R4: 字体升级

**预期**：
- 字号 15（原 14）
- 字重 Medium（原 Regular）
- 中文字体回退 `Microsoft YaHei UI`

**验收步骤**：
- [ ] 观察 todo 文字比之前略大、略粗
- [ ] 中英文混排（如"拒绝 bug 评审"）显示正常，中文不回退到 Tahoma

---

## ✅ R5: 整卡可点

**预期**：点击 todo 文字或整行空白区域 = 切换勾选

**验收步骤**：
- [ ] 点击 todo 文字右侧的空白区域，CheckBox 切换
- [ ] 点击文字本身，CheckBox 切换
- [ ] 点击 CheckBox 本身，CheckBox 切换

---

## ✅ R6: 已完成态 Opacity 0.55

**预期**：已完成项整行（CheckBox + 文字）透明度降低，视觉"沉下去"

**验收步骤**：
- [ ] 勾选一项，整行变暗（Opacity 0.55）
- [ ] 文字有删除线（原有功能）
- [ ] 取消勾选，整行恢复正常亮度

---

## ✅ R7: 空状态

**预期**：列表为空时显示「今天没有事项」居中灰色提示

**验收步骤**：
- [ ] 右键"编辑事项" → 删除所有 todo → 保存
- [ ] 主窗口显示「今天没有事项」，居中，灰色小字
- [ ] 添加一项 todo，提示消失

---

## ✅ R8: ContextMenu 暗色样式

**预期**：右键菜单为暗色背景，与主窗协调

**验收步骤**：
- [ ] 右键主窗口任意位置，弹出菜单
- [ ] 菜单背景为暗色（与主窗 `WindowBackgroundBrush` 一致）
- [ ] 菜单项文字为白色/浅灰
- [ ] 鼠标悬停菜单项，背景变为 `DividerBrush` 灰色
- [ ] 分隔线为细灰线

---

## 🔍 回归测试（确保未破坏既有功能）

- [ ] 窗口透明 + 圆角正常
- [ ] 窗口贴在桌面底层（不抢焦点）
- [ ] 关闭按钮 = 隐藏窗口（不退出进程）
- [ ] 托盘图标存在，右键"退出 Rhythm"才真退出
- [ ] Esc 键隐藏窗口
- [ ] 拖动窗口，位置持久化（重启后恢复）
- [ ] 勾选/取消勾选，状态持久化

---

## 🎨 视觉细节（主观评价）

- [ ] CheckBox 圆角 4px 观感舒适，不生硬
- [ ] 选中色 `#0A84FF` 与整体暗色主题协调
- [ ] 字号 15 + Medium 在 320px 宽窗口上可读性好
- [ ] 已完成项与未完成项层次分明
- [ ] 整体风格接近 macOS Reminders / Things 3

---

## ❌ 已知 Out of Scope（不验收）

- EditItemsWindow 视觉未同步（v3）
- 长文本换行（v3）
- 高 DPI 适配（v3）
- 卡片 hover 提亮、Space 键、分隔线、fade-in（P3 功能）

---

## 验收结论

- [ ] **通过**：所有 ✅ 项符合预期，回归测试无问题
- [ ] **不通过**：记录问题 → 修复 → 重新验收
