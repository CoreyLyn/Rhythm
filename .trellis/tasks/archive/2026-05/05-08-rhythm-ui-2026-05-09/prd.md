# 结合参考设计优化 Rhythm UI

## Goal

结合两个参考设计的优点，优化 Rhythm 主窗口的视觉呈现和交互体验：
- 参考设计 #2：浅色主题，简洁列表布局，蓝色强调色，时间标签
- 参考设计 #3：深色主题，卡片化布局，圆角方形复选框，已完成项删除线

## What I already know

### 当前实现（from codebase inspection）
- **技术栈**：WPF + .NET 10，XAML 样式定义在 `src/Rhythm/Themes/Dark.xaml`
- **主窗口**：`MainWindow.xaml`，透明圆角窗口，固定宽度 320px，高度自适应
- **当前样式**：
  - 深色主题：背景 `#1C1C1E` 78% 不透明度，圆角 10px
  - 复选框：18x18 圆角方形（4px），未选中灰色边框，选中蓝色填充 + 白色勾选动画
  - 文本：15px Medium，Microsoft YaHei UI / Segoe UI
  - 已完成项：55% 不透明度 + 删除线
  - 列表布局：垂直堆叠，每项 padding 10px
- **数据模型**：`Items[]` 包含 `Text` 和 `IsCompleted`，无时间字段
- **约束**：v1 锁定暗色主题（README 明确说明不做主题切换）

### 参考设计分析

**参考 #2（浅色）的可借鉴元素**：
- 顶部日期标题（"Thursday, 19 March"）
- 任务计数（"4 tasks"）蓝色强调
- 右上角圆形 "+" 按钮
- 时间标签右对齐（8:00AM, 10:30AM 等）
- 任务间细分隔线

**参考 #3（深色）的可借鉴元素**：
- 卡片化布局（每个任务独立圆角卡片背景）
- 圆角方形复选框（当前已有，但可调整样式）
- 已完成项删除线（当前已有）
- 标题 + 副标题结构（"Today's Tasks" + "Today's Oct 26"）

### 技术约束
- 必须保持深色主题（v1 不做主题切换）
- 窗口宽度固定 320px
- 数据模型当前无时间字段（需确认是否添加）
- 需保持透明圆角窗口特性

## Requirements

### 核心视觉改造
- **卡片化布局**：每个任务独立的深灰色圆角卡片背景（类似参考 #3）
  - 卡片背景色：比窗口背景稍亮的深灰（如 `#2C2C2E`）
  - 卡片圆角：6-8px
  - 卡片间距：8px
  - 卡片内边距：12px
- **顶部信息区**：
  - 日期标题：显示当前日期（格式："今天 5月8日" 或 "5月8日 星期四"）
  - 任务统计：显示完成进度（"已完成 2/5" 或 "3 个任务"）
  - 样式：标题较大（18-20px），统计文本使用强调色（蓝色 `#0A84FF`）
- **保持现有特性**：
  - 深色主题（`#1C1C1E` 背景）
  - 透明圆角窗口（10px 圆角，78% 不透明度）
  - 复选框交互动画（勾选弹性动画）
  - 已完成项视觉反馈（删除线 + 降低不透明度）
- **不添加**：
  - 时间字段（保持纯文本 + 复选框）
  - "+" 快速添加按钮（保持右键菜单编辑）

### 边缘情况处理
- **空状态优化**：
  - 调整 "今天没有事项" 提示样式，与卡片化布局协调
  - 可考虑添加图标或调整位置（居中显示）
- **长文本处理**：
  - 任务文本过长时自动换行（`TextWrapping="Wrap"`）
  - 最大行数限制（如 3 行），超出显示省略号
  - 卡片高度自适应文本内容
- **窗口高度限制**：
  - 任务过多时（如 10+ 项）限制窗口最大高度
  - 添加垂直滚动条（样式化以匹配深色主题）
  - 最大高度建议：屏幕高度的 70-80%（如 `MaxHeight="800"`）

### 细节规格（待实现时确定）
- 日期格式：优先 "今天 5月8日"（简洁），可选 "5月8日 星期四"
- 任务计数格式：优先 "已完成 2/5"（进度反馈），可选 "3 个任务"
- 卡片阴影：可选添加轻微阴影增强层次感（`DropShadowEffect`）
- 滚动条样式：细窄深色滚动条，hover 时显示

## Acceptance Criteria

- [ ] 卡片化布局实现：每个任务有独立圆角卡片背景，间距均匀
- [ ] 顶部信息区显示：日期 + 任务完成进度，样式清晰
- [ ] 空状态优化：无任务时提示样式与卡片布局协调
- [ ] 长文本处理：任务文本自动换行，超过 3 行显示省略号
- [ ] 窗口高度限制：任务过多时显示滚动条，最大高度不超过屏幕 80%
- [ ] 保持现有功能：勾选动画、删除线、右键菜单、拖动窗口均正常
- [ ] 视觉一致性：颜色、字体、圆角与现有深色主题协调
- [ ] 性能无退化：启动速度、勾选响应、窗口拖动流畅

## Definition of Done

- 代码实现完成（XAML + 样式更新 + ViewModel 属性）
- 手动测试：启动应用，验证视觉效果和交互（1 项、5 项、15 项、空状态、长文本）
- 无需数据迁移（状态文件 schema 不变）
- 更新 README（如有显著视觉变化）

## Technical Approach

### 文件修改清单
1. **`src/Rhythm/MainWindow.xaml`**：
   - 添加顶部信息区（日期 + 任务统计）
   - 将 `ItemsControl` 包裹在 `ScrollViewer` 中，设置 `MaxHeight`
   - 调整整体布局结构（Grid 行定义）

2. **`src/Rhythm/Themes/Dark.xaml`**：
   - 添加卡片样式（`ItemCardStyle`）：背景色、圆角、内边距、间距
   - 更新 `ItemCheckBoxStyle`：调整内边距以适配卡片布局
   - 更新 `ItemTextStyle`：添加 `TextWrapping` 和 `MaxLines`
   - 更新 `EmptyHintStyle`：调整空状态提示样式
   - 添加顶部信息样式（`HeaderDateStyle`、`HeaderStatsStyle`）
   - 添加滚动条样式（`ScrollViewerStyle`）

3. **`src/Rhythm/UI/MainViewModel.cs`**：
   - 添加 `CurrentDate` 属性（格式化日期字符串）
   - 添加 `CompletedCount` 属性（已完成任务数）
   - 添加 `TotalCount` 属性（总任务数）
   - 添加 `ProgressText` 属性（"已完成 2/5" 格式）
   - 在 `Items` 变化时触发属性更新（`PropertyChanged`）

### 实现策略
- **阶段 1**：添加顶部信息区 + ViewModel 属性（验证数据绑定）
- **阶段 2**：实现卡片化布局样式（验证视觉效果）
- **阶段 3**：添加滚动容器 + 高度限制（验证多任务场景）
- **阶段 4**：优化长文本处理 + 空状态样式（验证边缘情况）

### 关键设计决策
- **卡片背景色**：`#2C2C2E`（比窗口背景 `#1C1C1E` 稍亮，保持层次）
- **日期格式**：`DateTime.Now.ToString("M月d日 dddd", CultureInfo.GetCultureInfo("zh-CN"))`（如 "5月8日 星期四"）
- **进度格式**：`$"已完成 {CompletedCount}/{TotalCount}"`（当 TotalCount > 0 时显示）
- **最大高度**：`MaxHeight="600"`（约 10-12 个任务的高度，适配 1080p 屏幕）
- **文本换行**：`TextWrapping="Wrap"` + `MaxLines="3"` + `TextTrimming="CharacterEllipsis"`

### 数据模型变更
- **无需变更**：不添加时间字段，保持 `RhythmItem` 结构不变
- **状态文件兼容**：无 schema 变更，现有 `state.json` 无需迁移

## Out of Scope

- 浅色主题支持（v1 明确不做）
- 多主题切换
- 时间字段（保持纯文本任务）
- "+" 快速添加按钮（保持右键菜单编辑）
- 任务拖拽排序（保持编辑窗口排序）
- 动画效果的大幅改动（保持现有弹性动画）
- 窗口尺寸调整（保持 320px 固定宽度）
- 卡片阴影效果（可选，v1 不强制）
- 自定义配置项（字体、圆角、透明度等）
