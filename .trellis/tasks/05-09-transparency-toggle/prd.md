# PRD: 透明效果开关

## 背景
用户反馈 Rhythm 内存占用偏高 (~200-250MB)，主要原因是三个窗口都使用 `AllowsTransparency="True"` 透明背景，WPF 为每个分层窗口分配独立缓冲区。

## 目标
添加用户可控的开关，让用户可以选择是否启用透明效果，在视觉效果和内存占用之间取得平衡。

## 功能需求
- 在 state.json 添加 `enableTransparency: bool` 配置项（默认 true 保持现有行为）
- 托盘菜单添加可勾选的"透明效果"选项
- 切换开关时立即生效，无需重启
- 关闭透明效果时使用纯色背景（保持暗色风格）

## 技术方案
1. StateSchema.cs 添加 `EnableTransparency` 属性
2. App.xaml.cs 托盘菜单添加新 MenuItem
3. 窗口动态切换：
   - WPF 的 AllowsTransparency 不能在运行时切换
   - 方案：切换时关闭窗口，重建新窗口实例
   - 或：预先创建两套窗口，切换时显示/隐藏

## 预期效果
- 启用透明：~200-250MB（当前）
- 禁用透明：~80-120MB（预估）

## 验收标准
- 托盘菜单可见"透明效果"勾选项
- 切换后窗口立即更新外观
- state.json 正确保存设置
- 重启应用后设置保持
